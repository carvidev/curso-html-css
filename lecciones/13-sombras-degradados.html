Sombras, degradados y cursores

Tres efectos muy visuales que se consiguen con una sola línea de CSS: sombras, mezclas de color y cursores personalizados.

Sombras en cajas y en texto

box-shadow:  -5px 5px 5px black;
text-shadow:  2px 2px 4px blue;
/*           eje X, eje Y, desenfoque, color */
  • Eje X: positivo desplaza la sombra a la derecha, negativo a la izquierda.
  • Eje Y: positivo la baja, negativo la sube.
  • Desenfoque: cuanto mayor, más difuminada. Con 0 es un borde nítido.
  • Color: mejor con transparencia, como rgba(0, 0, 0, 0.3), para que quede natural.

Título con sombra de color

Título con efecto neón

.s-uno { box-shadow: 8px 8px 0 #26215C; }
.s-dos { box-shadow: 0 8px 24px rgba(0, 0, 0, .25); }
.s-texto-uno { text-shadow: 3px 3px 4px #F0997B; }
.s-texto-dos { color: #fff; background: #26215C;
    text-shadow: 0 0 8px #AFA9EC, 0 0 16px #7F77DD; }

Con text-shadow y box-shadow puedes poner varias sombras separadas por comas, como en el efecto neón.

Bordes redondeados y bordes con imagen

border-radius: 25px;              /* los cuatro lados */
border-radius: 10px 0 30px 0;     /* arriba-izq, arriba-der, abajo-der, abajo-izq */
border-radius: 50%;               /* círculo si la caja es cuadrada */

border: 1rem solid transparent;
border-image: linear-gradient(45deg, #534AB7, #1D9E75) 1;
Radios distintos
Círculo
Borde con degradado

Con border-image puedes usar una imagen o un degradado como borde. El 1 final indica cómo se recorta. Un borde con imagen y border-radius no se llevan bien: el redondeo no se aplica al borde.

Degradados

background-image: linear-gradient(to left, green, white, black);
background-image: radial-gradient(orange, white);
background: linear-gradient(to right,
    red 20%, orange 20% 40%, yellow 40% 60%, green 60% 80%, blue 80%);
  • linear: va en una dirección. Se indica con to left, to right, to top, to bottom o en grados (45deg).
  • radial: parte de un punto central hacia fuera.
  • Los porcentajes marcan dónde empieza y acaba cada color. Si dos colores comparten porcentaje, se ve un corte nítido y no un degradado.

Degradado con imagen y texto

Combina un degradado y una imagen en el mismo fondo. La imagen se ve a la izquierda y el color sólido a la derecha, con un título encima:

<div class="sobre">
    <h2>Muebles por encargo</h2>
</div>

.sobre {
    background-image:
        linear-gradient(to right, transparent 50%, #534AB7 50%),
        url(../img/paisaje.jpg);
    background-size: 100% 100%, cover;
    background-repeat: no-repeat;
    padding: 6rem 0;
    display: grid;
    grid-template-columns: repeat(2, 1fr);
}
.sobre h2 {
    grid-column: 2 / 3;
    text-align: center;
    color: white;
}

Bloque a un lado

Las capas de background-image se apilan: la primera queda encima. Por eso el degradado va delante, y background-size lleva un valor para cada capa, en el mismo orden.

Error común: poner la imagen antes que el degradado. Al quedar la imagen encima, el degradado ni se ve.

Cursores del ratón

h1 { cursor: help; }
a  { cursor: pointer; }

/* Un cursor propio, con uno normal como respaldo */
body { cursor: url('../img/cursor.png'), auto; }

Pasa el ratón por encima de cada caja:

help
crosshair
not-allowed
grab

Algunos valores habituales son pointer (la manita de los enlaces), text, wait, move, zoom-in, grab y not-allowed. Para uno propio, usa una imagen pequeña en .png o .cur, de 32x32 píxeles como máximo, y deja siempre un cursor normal de respaldo al final.

Truco: usa cursor: pointer en cualquier elemento que se pueda pulsar y no sea un enlace o un botón. Así el usuario sabe que es clicable.
