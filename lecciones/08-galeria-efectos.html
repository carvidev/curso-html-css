Galería, efectos y favicon

Una galería de imágenes es el uso más típico de CSS Grid: una rejilla de filas y columnas donde colocas fotos, vídeos, textos o bloques.

La galería con grid

<div class="galeria">
    <div class="foto"><img src="../img/paisaje.jpg" alt="Paisaje"></div>
    <div class="foto"><img src="../img/paisaje.jpg" alt="Paisaje"></div>
    <div class="foto"><img src="../img/paisaje.jpg" alt="Paisaje"></div>
</div>

.galeria {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    gap: 1.2rem;
}
.foto img {
    display: block;
    width: 100%;
    aspect-ratio: 4 / 3;
    object-fit: cover;
}

repeat(3, 1fr) crea tres columnas iguales y gap deja hueco entre ellas. Con aspect-ratio y object-fit: cover todas las fotos tienen la misma proporción aunque el original sea distinto, recortándose sin deformarse.

Truco: para que una celda ocupe más sitio, usa grid-column: span 2; (dos columnas) o grid-row: span 2; (dos filas).

Efectos al pasar el ratón

.foto { overflow: hidden; border-radius: .8rem; }
.foto img { transition: transform .4s, filter .4s; }

/* Efecto 1: zoom */
.zoom img:hover { transform: scale(1.15); }

/* Efecto 2: de gris a color */
.gris img { filter: grayscale(100%); }
.gris img:hover { filter: grayscale(0); }

/* Efecto 3: giro */
.giro img:hover { transform: rotate(5deg) scale(1.2); }

Tres piezas se combinan en cada efecto:

  • transition anima el cambio en lugar de hacerlo de golpe. Indicas qué propiedades y cuánto dura.
  • transform mueve, escala o gira el elemento (scale, rotate, translate).
  • filter aplica efectos visuales como grayscale, blur o brightness.
Error común: escalar una imagen sin overflow: hidden en su contenedor. Al crecer se sale de la celda y tapa a las vecinas.

El favicon

El favicon es el icono que aparece en la pestaña del navegador. Se enlaza desde el head de cada página:

<!-- desde index.html -->
<link rel="icon" href="img/favicon.svg" type="image/svg+xml">

<!-- desde lecciones/ -->
<link rel="icon" href="../img/favicon.svg" type="image/svg+xml">

Suele tener un tamaño pequeño: 32x32, 64x64 o hasta 512x512 píxeles. Puede ser .png, .ico o .svg. Los PDF muestran type="image/jpeg" y rel="shortcut icon", pero hoy basta con rel="icon".
