Cajas flotantes

Para CSS, cada elemento de la página es una caja. Entender cómo se calculan esas cajas es la base de toda la maquetación.

El modelo de caja

margin   → espacio exterior, entre esta caja y las demás
border   → el borde de la caja
padding  → espacio entre el borde y el contenido
content  → el contenido (texto, imágenes...)
margin: 20px;                /* los cuatro lados */
margin: 5px 5px 10px 10px;   /* arriba, derecha, abajo, izquierda */
border: black 2px solid;
border-radius: 25px;
padding: 10px;
padding-left: 10px;
Truco: empieza siempre tu CSS con * { margin: 0; box-sizing: border-box; }. Reinicia los márgenes y hace que el ancho incluya el padding y el borde.

La propiedad float

Cuando una caja flota, se desplaza hasta el extremo izquierdo o derecho de su contenedor y las demás se colocan a su lado.

float: left;    /* a la izquierda */
float: right;   /* a la derecha */
float: none;    /* valor por defecto, sin flotar */

Código

.izquierda { float: left; }
.derecha   { float: right; }

El problema: el contenedor se colapsa

Un contenedor solo contiene a sus hijos que no flotan. Si todos flotan, el contenedor se queda sin altura y su borde se queda en una línea:

Caja 1 Caja 2

Las cajas se salen de su contenedor: ha perdido la altura.

Dos soluciones

/* 1. overflow en el contenedor */
.limpiar { overflow: hidden; }

/* 2. clear en un elemento que va después */
.aparte { clear: both; }

La primera línea es la que ya aplica la demo de arriba, con .limpiar. La segunda es la que corrige el párrafo situado tras la demo rota, para que no se enrolle alrededor de las cajas. clear admite los valores left, right y both.

Error común: olvidar limpiar los flotantes. Si el fondo o el borde de un contenedor «desaparece» o el texto se mete al lado de las cajas, falta un overflow o un clear.

Ejemplo práctico: paginación

<div id="paginacion">
    <span class="izquierda">&laquo; Anterior</span>
    <span class="derecha">Siguiente &raquo;</span>
</div>

#paginacion {
    border: 1px solid #CCC;
    background-color: #E0E0E0;
    padding: .5em;
    overflow: hidden;
}
