Tablas

Una tabla organiza datos en filas y columnas. Úsala solo para eso: datos que se leen mejor en cuadrícula, como precios, horarios o comparativas.

Estructura básica

<table>
    <caption>Lenguajes más usados</caption>
    <tr>
        <th>Posición</th>
        <th>Lenguaje</th>
        <th>Uso</th>
    </tr>
    <tr>
        <td>1</td>
        <td>JavaScript</td>
        <td>Web</td>
    </tr>
    <!-- más filas -->
</table>
  • table es la tabla entera y caption su título.
  • tr (table row) es una fila.
  • th (table header) es una celda de cabecera. Va en negrita y centrada por defecto.
  • td (table data) es una celda de datos.

El CSS de la tabla

.tabla {
    width: 100%;
    border-collapse: collapse;
    border: 3px solid #26215C;
    background-image: linear-gradient(to bottom, rgba(83, 74, 183, .25), white);
    caption-side: bottom;
}
.tabla caption { margin: 1rem; }
.tabla th {
    background-color: #26215C;
    color: white;
    padding: 1rem;
    text-transform: uppercase;
}
.tabla td {
    padding: 1rem;
    text-align: center;
}
  • border-collapse: collapse fusiona los bordes de las celdas en uno solo. Sin ella, cada celda tiene su borde y queda un hueco doble.
  • caption-side: bottom pone el título debajo de la tabla.
  • El padding va en las celdas y no en la tabla: así respiran.
  • El degradado de fondo es el mismo de la lección 13, aplicado a la tabla entera.
Error común: usar tablas para maquetar la página (columnas, menús, cabecera). Es una práctica antigua que daña la accesibilidad y no se adapta al móvil. Para eso están flexbox y grid.

Cabecera, cuerpo y pie

En tablas largas conviene agrupar las filas según su función. Los navegadores y los lectores de pantalla las distinguen.

<table>
    <thead>
        <tr><th scope="col">Producto</th><th scope="col">Precio</th></tr>
    </thead>
    <tbody>
        <tr><td>Cuaderno</td><td>3 €</td></tr>
        <tr><td>Bolígrafo</td><td>1 €</td></tr>
    </tbody>
    <tfoot>
        <tr><th scope="row">Total</th><td>4 €</td></tr>
    </tfoot>
</table>
ProductoPrecio
Cuaderno3 €
Bolígrafo1 €
Carpeta2 €
Total6 €

El atributo scope dice si un th es la cabecera de una columna (col) o de una fila (row). Es una ayuda para la accesibilidad.

.tabla-rayas tbody tr:nth-child(even) { background-color: rgba(83, 74, 183, .12); }
.tabla-rayas tr:hover td { background-color: #EEEDFE; }

Las pseudoclases de la lección 6 sirven aquí para pintar filas alternas (nth-child(even)) y resaltar la fila bajo el ratón.

Combinar celdas

colspan="2"   /* la celda ocupa dos columnas */
rowspan="2"   /* la celda ocupa dos filas */
<table>
    <tr>
        <th rowspan="2">Sistema</th>
        <th colspan="2">Cuota</th>
    </tr>
    <tr>
        <th>2020</th>
        <th>2024</th>
    </tr>
    <tr>
        <td>Android</td><td>40 %</td><td>45 %</td>
    </tr>
</table>
Sistema Cuota
2020 2024
Android 40 % 45 %
iOS 30 % 28 %
Otros 30 % 27 %

Las cuotas son inventadas, solo sirven de ejemplo. Al combinar celdas, las filas siguientes tienen menos celdas, porque las que quedan tapadas no se escriben.

Truco: antes de escribir el HTML, dibuja la tabla en papel con las celdas combinadas. Cuenta cuántas celdas hay en cada fila: así no te equivocas con los colspan y rowspan.

Imágenes dentro de una tabla

Cualquier contenido cabe en una celda: texto, enlaces o imágenes. Es la base de las tablas comparativas de productos:

<td><img src="../img/paisaje.jpg" alt="Foto del producto"></td>
