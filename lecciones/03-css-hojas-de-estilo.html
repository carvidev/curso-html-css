CSS: hojas de estilo

CSS significa Hojas de Estilo en Cascada. Con HTML defines la estructura de la página y con CSS decides cómo se ve: colores, tamaños, espacios y posición.

Cómo se escribe una regla

selector {
    propiedad: valor;
}

h1 {
    color: orange;
    text-align: center;
}

El selector dice a qué elementos se aplica, y entre llaves van las declaraciones: cada propiedad con su valor y un punto y coma al final.

Tres formas de aplicar CSS

A. Con el atributo style, dentro de la etiqueta

<p style="font-family: Arial; font-size: 12px;">
    Este texto se ve en Arial de 12 píxeles
</p>

B. Con la etiqueta style, dentro del head

<head>
    <style>
        h1 { color: #00ff00; }
        p  { color: rgb(0, 0, 255); }
    </style>
</head>

C. Con un fichero independiente enlazado desde el head

<head>
    <link rel="stylesheet" href="css/estilos.css">
</head>
Truco: la opción C es la que usa esta web y la recomendada. Un solo fichero de estilos sirve para todas las páginas, y si cambias un color, cambia en todas.

Formas de escribir un color

color: red;                  /* nombre en inglés */
color: #004433;              /* código hexadecimal */
color: rgb(23, 56, 123);     /* rojo, verde, azul */
color: rgba(23, 56, 123, 0.7); /* con transparencia */

Selectores de relación

h1 + h2 { color: pink; }   /* un h2 justo después de un h1 */
h1 ~ h2 { color: pink; }   /* cualquier h2 hermano de un h1 */
p > span { color: pink; }  /* un span hijo directo de un p */
Error común: abusar de !important. Fuerza una regla por encima de todas las demás y luego es muy difícil de sobrescribir. Úsalo solo en último caso.
