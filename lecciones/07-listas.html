Listas

Hay tres tipos de listas en HTML: ordenadas (numeradas), desordenadas (con viñetas) y de definición.

Lista ordenada

Código

<ol>
    <li>España
        <ol>
            <li>Andalucía</li>
            <li>Madrid</li>
        </ol>
    </li>
    <li>Francia</li>
    <li>Italia</li>
</ol>

Resultado

  1. España
    1. Andalucía
    2. Madrid
  2. Francia
  3. Italia

Para anidar una lista, el ol interior va dentro del li al que pertenece, no suelto entre dos li.

<ol start="5">       <!-- empieza a contar en 5 -->
    <li>Quinto</li>
    <li value="10">Décimo</li>   <!-- este vale 10 -->
</ol>

Lista desordenada

Código

<ul>
    <li>Procesador</li>
    <li>Memoria RAM</li>
    <li>Disco SSD</li>
</ul>

Resultado

  • Procesador
  • Memoria RAM
  • Disco SSD

Lista de definición

Código

<dl>
    <dt>HTML</dt>
    <dd>Lenguaje de marcado de hipertexto</dd>
    <dt>CSS</dt>
    <dd>Hojas de estilo para dar diseño</dd>
</dl>

Resultado

HTML
Lenguaje de marcado de hipertexto
CSS
Hojas de estilo para dar diseño

dt es el término y dd su descripción.

Cambiar el estilo con CSS

list-style-type: none;          /* sin viñetas */
list-style-type: square;        /* cuadrados */
list-style-type: circle;        /* círculos vacíos */
list-style-type: lower-alpha;   /* a, b, c */
list-style-type: upper-roman;   /* I, II, III */

Una imagen como viñeta

.iconos li {
    list-style-type: none;
    background-image: url(../img/check.svg);
    background-size: 2rem;
    background-repeat: no-repeat;
    background-position: left center;
    padding: 0.4rem 0 0.4rem 3rem;
}
  • Ordenar las etiquetas
  • Cerrar cada etiqueta
  • Validar el código

Primero se quita la viñeta con list-style-type: none. Después se pone la imagen de fondo, se evita que se repita y se coloca a la izquierda. El padding-left deja hueco para que el texto no se pise con el icono.

Truco: la ruta dentro de url() en el CSS se mide desde el propio fichero CSS, no desde la página HTML.
Error común: usar <br> o guiones para simular una lista. Usa las etiquetas de lista, que dan significado a los lectores de pantalla.
