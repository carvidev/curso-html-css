Carrusel de imágenes

Un carrusel (o slider) muestra varias imágenes en el mismo espacio y deja pasar de una a otra. Aquí lo construimos con una fila horizontal, un ajuste automático al deslizar y dos botones.

El carrusel funcionando

1 / 5

Paso 1: el HTML

<div class="carrusel">
    <div class="pista">
        <figure class="diapo">
            <img src="..." alt="...">
            <figcaption>Imagen 1</figcaption>
        </figure>
        <!-- ... una figure por imagen ... -->
    </div>
    <div class="carrusel-controles">
        <button type="button" id="ant">Anterior</button>
        <span id="contador">1 / 5</span>
        <button type="button" id="sig">Siguiente</button>
    </div>
</div>

Hay tres capas: .carrusel es el conjunto, .pista es la tira larga con todas las diapositivas en fila y cada .diapo es una imagen con su pie.

Paso 2: la fila horizontal con CSS

.pista {
    display: flex;
    overflow-x: auto;
    scroll-snap-type: x mandatory;
}
.diapo {
    flex: 0 0 100%;
    scroll-snap-align: start;
}
  • display: flex coloca las diapositivas en fila.
  • flex: 0 0 100% hace que cada una mida exactamente el ancho de la pista y no se encoja.
  • overflow-x: auto deja que lo que no cabe se desplace en horizontal.
  • scroll-snap-type: x mandatory junto con scroll-snap-align: start hace que al deslizar la pista se pare siempre justo en el borde de una imagen, nunca a medias.

Solo con esto, ya puedes arrastrar con el dedo o con la rueda del ratón. Los botones son el siguiente paso.

Paso 3: los botones con JavaScript

const pista = document.querySelector('.pista');
const ant = document.getElementById('ant');
const sig = document.getElementById('sig');
const contador = document.getElementById('contador');
const total = pista.children.length;

function indice() {
    return Math.round(pista.scrollLeft / pista.clientWidth);
}

function ir(direccion) {
    pista.scrollBy({ left: direccion * pista.clientWidth, behavior: 'smooth' });
}

function actualizar() {
    const i = indice();
    contador.textContent = `${i + 1} / ${total}`;
    ant.disabled = i === 0;
    sig.disabled = i === total - 1;
}

ant.addEventListener('click', () => ir(-1));
sig.addEventListener('click', () => ir(1));
pista.addEventListener('scroll', actualizar);
actualizar();
  • scrollLeft es cuánto se ha desplazado la pista. Dividido entre su ancho, da el número de la imagen visible.
  • scrollBy con behavior: 'smooth' desplaza con animación una pantalla entera.
  • El evento scroll se dispara al deslizar, tanto con botones como con el dedo, así el contador y los botones siempre están al día.
  • disabled desactiva «Anterior» en la primera imagen y «Siguiente» en la última.
Truco: añade draggable="false" a las imágenes. Si no, al intentar deslizar con el ratón el navegador arrastra la foto como si quisieras copiarla.
Error común: olvidar flex: 0 0 100% y usar solo width: 100%. Los elementos flex se encogen para caber y todas las imágenes quedan comprimidas en el mismo espacio.

Extras

  • draggable="true": permite arrastrar cualquier elemento. Es lo contrario de lo que hemos puesto en las imágenes.
  • contenteditable="true": hace que el usuario pueda editar el texto del elemento directamente en la página. Prueba a pulsar en esta frase:

Haz clic aquí y escribe lo que quieras: este párrafo es editable.

Los cambios se pierden al recargar, porque solo ocurren en tu navegador. También puedes usar emoticonos directamente en el HTML (😀 🎬 ⭐), siempre que el fichero esté guardado en UTF-8.

Las pseudoclases :first-child y :last-child, que también aparecen en esa parte del Diario, ya las usaste en el menú de flexbox de la lección 6. Funcionan igual aquí, por ejemplo para darle esquinas redondeadas solo a la primera o a la última diapositiva.
