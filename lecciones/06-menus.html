Menús

Un menú es una lista de enlaces con estilo. No necesitas nada nuevo: usas listas, enlaces, display y :hover, y cambias solo la forma de colocarlos.

1. Menú horizontal con float

<nav class="menu-h">
    <ul>
        <li><a href="#">Inicio</a></li>
        <li><a href="#">Descargas</a></li>
        <li><a href="#">Registro</a></li>
    </ul>
</nav>

.menu-h { background-color: #534AB7; overflow: hidden; }
.menu-h ul { list-style: none; padding: 0; }
.menu-h li { float: left; }
.menu-h a {
    display: block;
    padding: 1.2rem 2rem;
    color: white;
    text-decoration: none;
}
.menu-h a:hover { background-color: #3C3489; }
  • Inicio
  • Descargas
  • Registro

Los li flotan a la izquierda para ponerse en fila, y overflow: hidden en el contenedor evita que se colapse, como viste en la lección 5.

Error común: poner el padding en el li en lugar de en el a. Así solo es clicable el texto. Con display: block y el padding en el enlace, lo es toda la zona.

2. Menú vertical

.menu-v { width: 20rem; background-color: #F1EFE8; }
.menu-v a {
    display: block;
    padding: 1rem 1.6rem;
    color: #2C2C2A;
    text-decoration: none;
    text-transform: uppercase;
}
.menu-v a:hover,
.menu-v a:active {
    background-color: #534AB7;
    color: white;
}
Principal Descargas Registro Novedades

Un enlace es inline por defecto. Con display: block pasa a ocupar su propia línea, y eso es lo que hace vertical al menú. :active se aplica mientras estás pulsando el enlace.

3. Menú con flexbox

.menu-flex { display: flex; background-color: #26215C; }
.menu-flex a {
    flex: 1;
    text-align: center;
    padding: 1.2rem;
    color: white;
    text-decoration: none;
}
.menu-flex a:first-child { border-radius: .8rem 0 0 .8rem; }
.menu-flex a:last-child  { border-radius: 0 .8rem .8rem 0; }
.menu-flex a:nth-child(even) { background-color: rgba(255, 255, 255, 0.08); }
.menu-flex a:hover { background-color: #534AB7; }
Inicio Servicios Galería Contacto

display: flex pone los enlaces en fila y flex: 1 les reparte el ancho a partes iguales. Las pseudoclases eligen enlaces por su posición: :first-child el primero, :last-child el último y :nth-child(even) los pares.

4. Menú con grid

.menu-grid {
    display: grid;
    grid-auto-flow: column;
    gap: .4rem;
}
.menu-grid a {
    text-align: center;
    padding: 1.2rem;
    background-color: #CECBF6;
    color: #26215C;
    text-decoration: none;
}
.menu-grid a:hover { background-color: #534AB7; color: white; }
Inicio Galería Ejemplos Contacto

grid-auto-flow: column hace que cada enlace ocupe una columna nueva. Cambiando a row en pantallas pequeñas pasa a vertical.
