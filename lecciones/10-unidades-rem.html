Unidades REM

En CSS puedes medir de muchas formas. px es fija, mientras que rem se calcula a partir del tamaño de letra del elemento raíz (html), y por eso se adapta mejor a cada usuario.

Qué es un rem

Un rem equivale al tamaño de letra de html. Los navegadores lo ponen por defecto a 16px, así que:

1rem   = 16px
2rem   = 32px
0.5rem = 8px

Está pensado para que las medidas respeten la configuración del usuario. Si alguien aumenta el tamaño de letra de su navegador, todo lo medido en rem crece con él, y lo medido en px no.

El truco del 62,5 %

Calcular con 16 es incómodo. Con este ajuste, 1rem pasa a valer 10px y las cuentas se hacen de cabeza:

html {
    box-sizing: border-box;
    font-size: 62.5%;   /* 62,5 % de 16px = 10px → 1rem = 10px */
}

body {
    font-size: 1.6rem;  /* el texto vuelve a medir 16px */
}

h1 {
    font-size: 4rem;    /* 40px */
}
  • html { font-size: 62.5% } hace que 1rem valga 10px.
  • body { font-size: 1.6rem } devuelve el texto a 16px. Sin esta línea, toda la página saldría diminuta.
  • Ahora 2.4rem son 24px, 3.2rem son 32px y 0.8rem son 8px.
Truco: usa un porcentaje en html y no font-size: 10px. El porcentaje respeta el tamaño que el usuario haya elegido en su navegador; los 10px lo ignoran.

rem frente a em

rem → relativo al tamaño de letra de html (la raíz)
em  → relativo al tamaño de letra del elemento (o de su padre)
padding: 1em (cabe con 2rem de letra) 
.em-demo { font-size: 2rem; }
.em-caja { padding: 1em; }   /* 1em = 20px, porque el padre mide 2rem */

El em se acumula si lo anidas: un em dentro de otro em se multiplica. El rem siempre se calcula desde la raíz, así que es más predecible.

Error común: usar rem dentro de una media query esperando que valga 10px. Allí se mide con el tamaño de letra por defecto del navegador, no con el de tu html. Por eso en las media queries es mejor px.

Cuándo usar cada unidad

  • rem: tamaños de letra, márgenes, rellenos y anchos de componentes.
  • px: bordes finos (1px) y sombras.
  • %: anchos relativos al contenedor.
  • vh / vw: relativos al alto o ancho de la ventana.
