Fuentes de texto

La tipografía da personalidad a una web. Puedes usar las fuentes que ya tiene el ordenador del usuario, fuentes de Google o tus propios ficheros.

font-family y las fuentes de respaldo

p {
    font-family: Arial, Helvetica, sans-serif;
}

Se escribe una lista de fuentes separadas por comas. El navegador usa la primera que tenga y, si no, pasa a la siguiente. La última debe ser siempre una familia genérica: sans-serif, serif, monospace o cursive.

A. Fuentes online: Google Fonts

  1. Entra en fonts.google.com y elige una fuente.
  2. Pulsa «Get font» y «Get embed code».
  3. Copia las etiquetas link en el head de tu página.
  4. Copia la regla font-family que te da Google en tu CSS.
<head>
    <link rel="preconnect" href="https://fonts.googleapis.com">
    <link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
    <link href="https://fonts.googleapis.com/css2?family=Press+Start+2P&display=swap"
        rel="stylesheet">
</head>

.retro {
    font-family: 'Press Start 2P', monospace;
}

Así quedaría nuestro texto con otra fuente.

Un título con otra fuente

  • preconnect avisa al navegador de que va a pedir recursos a esos dominios, para que ganen tiempo. En fonts.gstatic.com hace falta crossorigin.
  • display=swap muestra el texto con una fuente de respaldo mientras se descarga la tuya, en lugar de dejarlo invisible.
  • Si pides varios pesos, como wght@400;700, se descargan más datos. Pide solo los que uses.
Error común: aplicar la fuente con * { font-family: ... } y con cursive como respaldo, como en los apuntes. Afecta a absolutamente todo y, si la fuente falla, el respaldo no se parece a ella. Aplícala con una clase o a body, y elige un respaldo parecido (monospace para una fuente de estilo píxel).

B. Fuentes offline: @font-face

También puedes usar un fichero de fuente guardado en tu proyecto, sin depender de ninguna conexión. Descarga una fuente (por ejemplo de Google Fonts o DaFont), guárdala en una carpeta fonts/ y declárala en el CSS:

@font-face {
    font-family: "MiFuente";
    src: url("../fonts/mifuente.woff2") format("woff2");
    font-display: swap;
}

.titulo-propio {
    font-family: "MiFuente", sans-serif;
    font-size: 5rem;
}

@font-face inventa un nombre para la fuente (font-family) y le dice de dónde cargarla (src). Después usas ese nombre como cualquier otra. Prefiere el formato .woff2, que es el más ligero. Otros como .ttf también funcionan.

Truco: como en el CSS, la ruta dentro de url() se mide desde el fichero .css, por eso lleva ../: sales de css/ y entras en fonts/.

Reparte las fuentes por función

Una web cuidada usa pocas fuentes, cada una con su papel:

body    { font-family: system-ui, sans-serif; }      /* texto */
h1, h2  { font-family: 'Playfair Display', serif; }  /* títulos */
.menu   { font-family: 'Press Start 2P', monospace; } /* menú */

Con dos o tres fuentes es suficiente. Cada una más es una descarga extra, y muchas mezcladas hacen que la web parezca caótica.
