Display y plantilla semántica

La propiedad display decide cómo se coloca un elemento respecto a los demás. Hay tres sistemas para maquetar: float, flexbox y grid.

block, inline e inline-block

display: block;         /* ocupa toda la línea, admite width y height */
display: inline;        /* se coloca en la línea, NO admite width ni height */
display: inline-block;  /* se coloca en la línea, SÍ admite width y height */
block block inline inline inline-block inline-block

Los tres tienen width: 20rem, pero el inline la ignora y se ajusta a su contenido. Las etiquetas div, p y h1 son block por defecto, y span y a son inline.

Float

float: left;    float: right;
clear: both;    /* para dejar de flotar */

Es el sistema clásico, el que viste en la lección 5. Funciona, pero hay que limpiar los flotantes. Hoy se usa sobre todo para que el texto rodee una imagen.

Flexbox: diseño flexible en una dimensión

.fila {
    display: flex;
    flex-direction: row;            /* o column */
    justify-content: space-between; /* reparto en el eje principal */
    align-items: center;            /* alineación en el eje cruzado */
    gap: .8rem;
}
.fila .ancho { flex: 1; }           /* ocupa el espacio sobrante */
Uno Dos (flex: 1) Tres
Uno Dos Tres

Flex reparte los elementos a lo largo de un eje principal, que es horizontal con row y vertical con column. justify-content los coloca a lo largo de ese eje y align-items en el eje perpendicular.

Error común: pensar que justify-content es siempre horizontal y align-items siempre vertical. Eso solo es así con row. Con column, cada propiedad cambia de eje.

Grid: diseño en rejilla de dos dimensiones

.rejilla {
    display: grid;
    grid-template-columns: repeat(3, 1fr);   /* tres columnas iguales */
    gap: .8rem;
}
.rejilla.auto { grid-auto-flow: column; }    /* cada hijo, una columna */
1 2 3 4 5 6
Truco: flexbox para organizar elementos en una fila o en una columna (menús, barras, tarjetas). Grid para estructuras con filas y columnas a la vez (galerías, la página entera).

La plantilla semántica de HTML5

HTML5 trae etiquetas que describen la función de cada parte de la página, en lugar de usar div para todo:

<body>
    <header>   Cabecera: logo, título        </header>
    <nav>      Menú de navegación            </nav>
    <main>
        <section>  Un bloque con un tema      </section>
        <article>  Contenido independiente    </article>
    </main>
    <aside>    Contenido secundario (lateral) </aside>
    <footer>   Pie de página                  </footer>
</body>

Visualmente se parecen a los div, pero ayudan a los buscadores y a los lectores de pantalla a entender la estructura. Tu propia web ya usa header, nav y main.
