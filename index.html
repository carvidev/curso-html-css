Qué es HTML

HTML son las siglas de Hyper Text Markup Language. Es el lenguaje con el que se escriben las páginas web.

Código HTML

<h1>Hola mundo</h1>
<p>Mi primera página</p>

Resultado

Hola mundo

Mi primera página

Truco: en VS Code escribe ! y pulsa Tab para generar la plantilla base.
Error común: olvidar cerrar una etiqueta. Cada <p> necesita su </p>.
